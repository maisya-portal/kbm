Pasang Aplikasi Presensi KBM

Panduan pemasangan di berbagai browser

Untuk Browser Chrome / Samsung Internet / Firefox
Aplikasi akan terpasang langsung di menu dan beranda HP Anda.
  1. Buka Menu Browser
    Ketuk ikon titik tiga () di pojok kanan atas browser Anda.
  2. Pilih "Install Aplikasi"
    Cari dan pilih opsi "Install aplikasi" atau "Tambahkan ke Layar Utama" (Add to Home screen) ().
  3. Konfirmasi Pemasangan
    Ketuk "Install" atau "Tambah". Ikon Presensi KBM kini siap digunakan langsung dari layar HP.
Untuk iPhone & iPad (Browser Safari)
Apple mewajibkan instalasi PWA dilakukan melalui menu Share Safari.
  1. Gunakan Browser Safari
    Pastikan Anda membuka halaman ini di browser Safari bawaan iPhone/iPad.
  2. Ketuk Tombol Share (Bagikan)
    Ketuk tombol Share () di bilah navigasi bagian bawah layar.
  3. Pilih "Add to Home Screen"
    Gulir ke bawah dan ketuk opsi "Tambahkan ke Layar Utama" / "Add to Home Screen" ().
  4. Ketuk "Tambah" (Add)
    Ketuk tombol "Tambah" / "Add" di pojok kanan atas untuk menyelesaikan.
Untuk Komputer / Laptop (Windows & Mac)
Aplikasi akan berjalan di jendela khusus yang ringan tanpa gangguan tab browser.
  1. Klik Ikon Install di Address Bar
    Pada Google Chrome atau Microsoft Edge, klik ikon Install () di sebelah kanan kolom URL.
  2. Atau Buka Menu Titik Tiga Browser
    Klik menu titik tiga di pojok kanan atas → pilih "Simpan dan bagikan" / "Aplikasi" → klik "Install Presensi KBM".
  3. Selesai!
    Aplikasi akan dibuatkan pintasan di Desktop dan Start Menu Anda.
